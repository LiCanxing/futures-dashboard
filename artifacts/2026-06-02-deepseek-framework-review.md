# 期货品种分析框架评审 — 2026-06-02

## 背景
老板与DeepSeek讨论了以鸡蛋JD2607为案例的期货品种分析框架（"四层漏斗"），让我阅读后给出补充建议。

## 框架已有部分（评价：扎实）

### 四层漏斗结构
1. **第一层：宏观周期与产业定位** — 判断方向
2. **第二层：供需平衡表与库存** — 建立价格锚
3. **第三层：现货层面的实时验证** — 确认驱动
4. **第四层：盘面结构与资金行为** — 确认时机

### 亮点模块
- 历史案例统计：8个牛市案例 + 4个熊市案例 + 2个极端案例
- 提保死亡螺旋：入场信号→加速赶顶→支撑保护→三重死亡螺旋
- JD2607五驱动力拆解：供给断档→库存枯竭→深贴水→旺季→情绪正反馈
- 品种泛化：分农产品/工业品/能源/贵金属四类参数替换

## 建议补充的6个维度

1. **展期收益（Roll Yield）** — 期限结构不仅是方向信号，还产生展期损益
2. **期权隐含波动率（IV）** — 前瞻性情绪指标，有期权品种可监控
3. **汇率传导** — 铁矿石、铜、大豆等进口依赖品种必须纳入
4. **跨品种价差与替代效应** — 豆粕↔菜粕、玉米↔小麦等关联分析
5. **季节性量化统计** — 从定性故事到定量胜率/收益统计
6. **信号强度→仓位映射** — 四层共振度决定仓位和风控策略

## 结论
框架骨架扎实，补充方向聚焦：增加信号源 + 增加量化与执行闭环。
